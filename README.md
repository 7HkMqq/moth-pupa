# Moth pupa 🦋

Многостраничный сайт интернет-магазина одежды, выполненный в рамках контрольной работы №1 по HTML и CSS.

## 🔗 Ссылка на живой сайт
[Открыть сайт Moth pupa](https://7hkmqq.github.io/moth-pupa/)

## 📌 О проекте
Сайт разработан без использования CSS-фреймворков и JavaScript. Основной упор сделан на семантическую разметку, адаптивную верстку, современное оформление и публикацию на GitHub Pages.

## 🛠 Технологии
* HTML5 (семантическая разметка: `header`, `nav`, `main`, `section`, `footer`)
* CSS3 (Flexbox, CSS Grid)
* CSS-переменные (`:root`)
* BEM-нейминг (для карточек товаров)
* Псевдоклассы `:hover` и `:focus-visible`

## 📄 Страницы сайта
* `index.html` — Главная страница (баннер, преимущества, хиты продаж)
* `catalog.html` — Каталог (таблица размеров, сетка товаров)
* `about.html` — О нас (информация о бренде)
* `contacts.html` — Контакты (форма обратной связи)

## 📁 Структура проекта
* `index.html` — Главная
