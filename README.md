# Moth pupa 🦋

Многостраничный сайт интернет-магазина одежды, выполненный в рамках контрольной работы №1 по HTML и CSS.

## 📌 О проекте
Сайт разработан без использования CSS-фреймворков и JavaScript. Основной упор сделан на семантическую разметку, адаптивную верстку и современное оформление.

## 🛠 Технологии
* HTML5 (семантическая разметка)
* CSS3 (Flexbox, CSS Grid)
* CSS-переменные
* BEM-нейминг

## 📄 Страницы сайта
* `index.html` — Главная страница
* `catalog.html` — Каталог товаров
* `about.html` — О бренде
* `contacts.html` — Контакты
