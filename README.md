# Moth pupa 🦋

Многостраничный сайт интернет-магазина одежды, выполненный в рамках контрольной работы №1 по дисциплине "HTML и CSS".

## 🔗 Ссылка на живой сайт (GitHub Pages)
[Открыть сайт Moth pupa](https://7hkmqq.github.io/moth-pupa/)

## 📌 О проекте
Сайт разработан с нуля без использования CSS-фреймворков и JavaScript. Основной упор сделан на семантическую разметку, современное оформление, адаптивную сетку и публикацию проекта в интернете.

## 🛠 Реализованные требования (Чек-лист КР №1)
- [x] Многостраничный сайт (Главная, Каталог, О нас, Контакты)
- [x] Семантическая HTML-разметка (`header`, `nav`, `main`, `section`, `footer`)
- [x] Единая навигация между страницами
- [x] Якорные ссылки (переход к блоку "Хиты продаж")
- [x] Карточки товаров с изображениями и ценами
- [x] Таблица характеристик (таблица размеров)
- [x] Форма обратной связи (страница "Контакты")
- [x] Внешний файл стилей `style.css`
- [x] CSS-переменные (`:root`)
- [x] Состояния элементов (`:hover`, `:focus-visible`)
- [x] Сетки: Flexbox и CSS Grid
- [x] Базовое позиционирование (`relative`, `absolute` для бейджа "Хит", `sticky` для шапки)
- [x] Базовое BEM-именование классов (`.product-card__img`, `.product-card__title` и т.д.)
- [x] Публикация проекта на GitHub Pages

## 📁 Структура файлов
* `index.html` — Главная страница
* `catalog.html` — Каталог товаров с таблицей размеров
* `about.html` — Информация о бренде
* `contacts.html` — Форма обратной связи
* `style.css` — Единый файл стилей для всего сайта
* `*.jpg` — Изображения товаров
